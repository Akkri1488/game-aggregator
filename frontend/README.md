# GamePrice — фронтенд (React + Vite)

Веб-интерфейс агрегатора цен на игры. Подключается к бэкенду и показывает
каталог, сравнение цен между магазинами, скидки и историю цен.

## Запуск

### 1. Сначала запусти бэкенд
В папке `backend`:
```bash
node index.js
```
Бэкенд должен работать на порту **5001** (порт задаётся в `backend/.env`).
Если база ещё пустая — сначала наполни её:
```bash
RUN_PARSERS=true node index.js
```

### 2. Запусти фронтенд
В папке `frontend` (один раз — установка библиотек):
```bash
npm install
```
Затем каждый раз для запуска:
```bash
npm run dev
```
Открой в браузере адрес, который покажет Vite — обычно:
```
http://localhost:5173
```

## Если бэкенд на другом порту
Открой `vite.config.js` и поменяй `target: 'http://localhost:5001'`
на свой порт. Перезапусти `npm run dev`.

## Что внутри
- **Каталог** — все игры с ценами по платформам, поиск, фильтр по платформе, сортировка.
- **Где дешевле** — игры, найденные на 2+ магазинах; зелёным выделена лучшая цена.
- **Скидки** — топ скидок с фильтром по проценту.
- **Карточка игры** (по клику) — цены на всех платформах, ссылки в магазины, график истории цен.

## Технологии
- React 18
- Vite (сборщик и dev-сервер)
- Recharts (график истории цен)
